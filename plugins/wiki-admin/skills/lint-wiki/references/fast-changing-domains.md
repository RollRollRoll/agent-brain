# 快速变化的领域

`/wiki-admin:lint-wiki` 的「可能过时」检查用本表判断领域是否快速变化，判定规则见该 skill。

收录标准：这个领域的推荐做法、版本或产品现状通常在一两年内明显变化。表里没有的标签一律视为变化慢。

| 领域标签 | 为什么算快速变化 |
|---|---|
| 前端框架 | 主流框架和构建工具一两年就换代，推荐做法跟着变 |
| 前端开发 | 同上，浏览器 API 和工具链更新频繁 |
| AI | 模型、接口和最佳实践按月变化 |
| LLM | 同上 |
| 机器学习 | 框架版本和推荐模型变化快 |
| 云服务 | 产品、定价和配额经常调整 |
| DevOps | CI/CD、容器编排工具版本迭代快 |
| 安全 | 漏洞和防护建议持续更新 |
| 移动开发 | 平台每年发布新版本，API 和审核规则随之变化 |

`软件开发`、`知识管理` 这类宽泛标签**不在表中**：它们覆盖的大多是原理和方法，变化慢；
放进来会让几乎所有页面都被标记，报告失去意义。

Wiki 里出现了新的快速变化领域时，把标签加到上表，并写明理由。
