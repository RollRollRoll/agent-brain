用带 frontmatter 的模板把网页剪藏成 Markdown，存进原始材料目录。

## 前置条件

- 浏览器已安装 Obsidian Web Clipper 扩展
- Obsidian vault 里有原始材料目录（例如 `raw/`）

## 所需工具

- Obsidian
- Obsidian Web Clipper 浏览器扩展

## 步骤

1. 在 Web Clipper 设置里新建模板，把保存位置设为原始材料目录。
2. 在模板的 frontmatter 里加上标题、来源 URL、作者和剪藏日期四个字段。
3. 打开要剪藏的网页，用这个模板剪藏。
4. 在 vault 里确认新文件的 frontmatter 四个字段都有值。
